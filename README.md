# Khas — демонстрационный сайт федерации IKO WKK

Сайт-пример для федерации IKO WKK по киокушинкай каратэ. Статический проект: HTML, CSS и JavaScript, без сборки и сервера.

## Файлы

- `index.html` — четыре раздела: главная, о федерации, пресс-центр и контакты.
- `styles.css` — оформление, адаптивная вёрстка и мобильная навигация.
- `app.js` — переключение разделов, фильтры и загрузка иллюстраций.
- `images.js` — **все ссылки на фотографии собраны в одном месте**.
- `favicon.svg` — иконка сайта.

## Как заменить изображения

Открой `images.js`. Например:

```js
hero: "https://example.com/photo.jpg",
athlete1: "img/img1.jpg",
```

Для локальных фотографий создай папку `img` в корне проекта (рядом с `index.html`) и положи туда изображения. Затем укажи путь в `images.js`. Менять HTML и CSS не требуется.

## Источники демонстрационных фото

Фотографии взяты с Wikimedia Commons. Условия лицензий и авторство указаны комментариями в `images.js`; при дальнейшем использовании сохрани атрибуцию и соблюдай условия соответствующих лицензий. Иллюстрации не изображают подтверждённых представителей IKO WKK Kazakhstan.

## Важно перед реальным использованием

Все ФИО, статистика, должности, филиалы, даты, адреса и контакты являются демонстрационными. Сверь официальное написание названия организации и её принадлежность к IKO WKK, а затем замени данные на подтверждённые. Не используй макет как официальный ресурс без согласования с федерацией.

## Запуск

Открой `index.html` или включи GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
