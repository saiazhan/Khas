# Khas — сайт федерации боевых искусств

Адаптивный сайт-визитка федерации киокусинкай. Проект работает без сборщика и серверной части: достаточно открыть `index.html` в браузере или опубликовать репозиторий через GitHub Pages.

## Структура

- `index.html` — три раздела сайта: главная, федерация и тренеры, новости и календарь.
- `styles.css` — адаптивный дизайн, сетки, мобильная навигация и визуальные заглушки изображений.
- `app.js` — переключение разделов и фильтры по городам и категориям новостей.

## Запуск

Откройте `index.html` в браузере. Для публикации включите GitHub Pages в настройках репозитория: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Перед публикацией

В текущей версии намеренно используются демонстрационные данные и текстовые заглушки вместо фотографий. Перед официальным запуском замените:

- название и логотип федерации;
- историю, статистику и достижения на подтверждённые данные;
- адреса филиалов и направления тренировок;
- ФИО, степени и стаж тренеров;
- даты, города, статусы мероприятий и новости;
- почту `info@example.kz` и ссылку записи на реальные контакты.

Внешние фотографии не подключены. Шрифт Manrope/Oswald загружается из Google Fonts; при отсутствии подключения браузер использует системные шрифты.
